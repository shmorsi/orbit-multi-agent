# Corpus

These files are a small fictional makerspace log used as a bundled retrieval corpus. A second fictional corpus, a checkout outage, lives in `data/scenarios/incident/` and is not part of the frozen test. They are not a public dataset and they are not economic data. `data/manifest.json` records a sha256 for each file. The tools refuse to read anything outside this directory, and `web_cache.json` is an offline page cache: search never opens a network connection.
