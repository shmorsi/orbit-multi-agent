# Corpus

These files are a small fictional makerspace log used as a bundled retrieval corpus. A second fictional corpus, a checkout outage, lives in `data/scenarios/incident/` and is not part of the frozen test. Frozen code splits live in `data/scenarios/code/` (`code-eval-v1`) and `data/scenarios/code_v2/` (`code-eval-v2`). The current score command uses `code-eval-v2`. `code-eval-v2` is pending, not scored. A fictional company corpus for the boardroom demo lives in `data/scenarios/boardroom/`. Neither one is the makerspace test. They are not a public dataset and they are not economic data. `data/manifest.json` records a sha256 for each file. The tools refuse to read anything outside this directory, and `web_cache.json` is an offline page cache: search never opens a network connection.
